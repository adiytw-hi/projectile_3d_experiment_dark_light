Equations, assumptions, and access

Coordinate system: x = horizontal distance (m), y = height (m), z = sideways depth (m; always 0 for these trajectories). Positive gravity magnitude g acts downward. Flight begins at x = y = 0, returns to y = 0, and the ground is level. Object size and bounce are not simulated.

Ideal model (drag off): x(t) = v₀ cos(θ)·t; y(t) = v₀ sin(θ)·t − ½gt²; vₓ(t) = v₀cos(θ); vᵧ(t) = v₀sin(θ) − gt. T = 2v₀sin(θ)/g; H = v₀²sin²(θ)/(2g); R = v₀²sin(2θ)/g.
Simplified linear drag (toggle on): aₓ = −kvₓ; aᵧ = −g − kvᵧ, where k has units s⁻¹. vₓ = v₀ₓe−kt; vᵧ = (v₀ᵧ+g/k)e−kt − g/k; x = (v₀ₓ/k)(1−e−kt); y = ((v₀ᵧ+g/k)/k)(1−e−kt) − gt/k. Landing time is found numerically from y(T) = 0. This is not a real-world drag coefficient, mass-dependent ballistics model, or quadratic drag law.

Accessibility: All adjustable values also have keyboard-accessible sliders. Focus the 3D field and use ←/→ to orbit horizontally, ↑/↓ to change elevation, and +/− to zoom. Toggle 2D for an overhead-free graph view. The interactive field and plots are supplemented by text readouts and comparison tables. The chart can be operated by mouse/touch; use the time slider as its accessible equivalent. Reduced-motion preferences suppress automatic animated movement.

Numerical precision: Displayed values are rounded, but calculations use unrounded double-precision values. For the numeric quiz a tolerance of max(0.15 m, 1% of range) is accepted. Altering launch parameters pauses and resets the timeline and clears the dependent numeric answer. Both trajectories are computed with one common clock; a completed launch rests on the ground.
